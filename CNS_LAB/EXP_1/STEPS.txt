Step 1: Open Cisco Packet Tracer
1. Open Cisco Packet Tracer on your computer.
2. Click on File → New.
3. A blank workspace will appear.



Step 2: Add networking devices
1. Go to the bottom-left device selection panel.
2. Click Network Devices.
3. Select Switches.
4. Drag a Cisco 2960 switch into the workspace.
5. Click End Devices.
6. Drag four PCs into the workspace.
Arrange the devices as shown:




Step 3: Connect the devices using cables
1. Click the Connections icon (lightning symbol).
2. Select Copper Straight-Through Cable.
3. Connect the devices as follows:
Source Device	Port	Destination Device	Port
PC0	FastEthernet0	Switch0	                Fa0/1
PC1	FastEthernet0	Switch0         	Fa0/2
PC2	FastEthernet0	Switch0			Fa0/3
PC3	FastEthernet0	Switch0			Fa0/4

4. Wait for the link indicators to turn green.



Step 4: Configure IP addresses
Each computer needs a unique IP address to communicate within the LAN.

Configure PC0:
1. Click PC0.
2. Select Desktop.
3. Open IP Configuration.
4. Select Static.
5. Enter:
Setting	Value
IP Address	192.168.1.1
Subnet Mask	255.255.255.0
Default Gateway	Leave blank

Configure the remaining PCs:
Computer	IP Address		Subnet Mask
PC0		192.168.1.1		255.255.255.0
PC1		192.168.1.2		255.255.255.0
PC2		192.168.1.3		255.255.255.0
PC3		192.168.1.4		255.255.255.0

Repeat the same IP configuration process for all four computers.


Step 5: Test LAN connectivity using the Ping command
Now check whether all computers can communicate with each other.
1. Click PC0.
2. Select Desktop.
3. Open Command Prompt.
4. Enter the following command:
ping 192.168.1.2


This command tests communication between PC0 and PC1.

Similarly, execute:
ping 192.168.1.3
ping 192.168.1.4









itnetwork.cz


Expected output: You should receive successful ping replies from the destination computers. The first ping may occasionally time out while ARP resolves the destination MAC address; try again.
Step 6: Observe packet transmission
1. Select Simulation Mode at the bottom-right corner.
2. Click Add Simple PDU (envelope icon).
3. Click PC0 as the source.
4. Click PC1 as the destination.
5. Observe the packet moving through the switch.
6. Click Capture/Forward to inspect packet transmission step by step.
